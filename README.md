# theannotatedpast/sources

Public source pages for The Annotated Past, served by GitHub Pages at
https://theannotatedpast.github.io/sources/.

Pages are generated, not hand-written: in the channel project run
`python scripts/vidtool.py sources-page <slug>` and then
`python scripts/vidtool.py publish-sources <slug>`, which writes `<slug>/index.md` here and
adds the video to `index.md`. Commit and push by hand.
